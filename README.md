# Games Cyox - Home e Login

Atividade avaliativa do curso **Codificação Front-End (SENAI)**, referente ao desenvolvimento das páginas **Home** e **Login** de um site fictício de e-commerce de jogos (LH Games), a partir de um layout já definido.

## 📋 Descrição da atividade

O objetivo foi desenvolver as páginas `index.html` (home) e `login.html`, aplicando:

- **HTML5** e **CSS3** para marcação e estilização;
- **Bootstrap** para a construção de componentes (navbar, carousel, cards) e responsividade;
- **JavaScript** e **jQuery** para implementação de interatividade e validação de dados.

## ✨ Funcionalidades

**Home (`index.html`)**
- Menu de navegação (navbar) responsivo, com logo, links de navegação e campo de busca;
- Carousel de banners de destaque;
- Seção "Os mais vendidos" com cards de produtos (imagem, título, descrição, preço e botão de compra);
- Rodapé fixo;
- Botão "Voltar ao topo" com rolagem suave via JavaScript.

**Login (`login.html`)**
- Formulário de login com validação simples via JavaScript (usuário/senha fixos para teste);
- Alerta de "Acesso negado" para credenciais incorretas e redirecionamento para a home em caso de sucesso;
- Formulário de cadastro exibido/ocultado dinamicamente com efeito `slideToggle` (jQuery);
- Alerta de confirmação de cadastro com redirecionamento para a home;
- Botão "Voltar ao topo" com rolagem suave.

## 🛠️ Tecnologias utilizadas
